Fluxos do Sistema

Jornadas principais do usuário

🔐 Fluxo de Autenticação

→ App Abre
→ Verifica JWT local (AsyncStorage)
✅ Token válido → Dashboard
⚠️ Token expirado → Refresh Token
✅ Refresh ok → Dashboard
❌ Refresh falhou → Tela de Login
❌ Sem token → Tela de Login
→ Usuário faz login
→ POST /api/auth/login
✅ Salva JWT → Dashboard
❌ Erro → Mensagem de erro

🛒 Fluxo de Compra

→ Usuário clica em "Nova Compra"
→ Seleciona Fornecedor
→ Adiciona Produtos + Quantidades
→ Sistema sugere menor cotação
→ Informa Valores Unitários
→ Calcula Total automaticamente
→ Anexa Nota Fiscal (opcional)
→ Confirma Salvar
✅ Atualiza Dashboard
✅ Atualiza Indicadores Financeiros
✅ Atualiza Quantidade Comprada
→ Verifica se atingiu 80% do orçamento
⚠️ Se sim → Notificação push

💲 Fluxo de Cotação

→ Usuário acessa Produto
→ Clica em "Cotações"
→ Vê lista de preços por fornecedor
→ Menor preço destacado em verde
→ Exibe economia potencial
→ Pode adicionar nova cotação
→ Seleciona Fornecedor
→ Informa preço e validade
✅ Salva e reordena lista
→ Pode clicar "Comprar do Melhor"
→ Pré-preenche tela de Nova Compra

📊 Fluxo do Dashboard

→ Carrega Dashboard da Obra
→ GET /api/obras/{id}/dashboard
→ Exibe KPIs em tempo real:
• Valor planejado / gasto / restante
• % consumido
• Total de compras do mês
→ Gráfico de gastos por mês (barras)
→ Gráfico por categoria (pizza)
→ Status de cada etapa
→ Últimas compras (timeline)
→ Alertas e notificações
→ Atualiza a cada 30s
